# Cope Saund Mahdi 🔊

تطبيق أندرويد أنيق (Material Design 3) للاستنساخ الصوتي — سجّل عيّنة قصيرة، اكتب النص، واحصل على صوت مستنسخ. يتضمن المستودع: التطبيق (Kotlin + Jetpack Compose)، خادم استنساخ خفيف (Chatterbox — MIT)، وبناء/توقيع APK تلقائياً عبر GitHub Actions.

> ⚠️ **الاستخدام المسؤول**: استنسخ الأصوات التي تملك الحق في استخدامها فقط. لا تستخدم التطبيق لانتحال أشخاص أو تضليل. مخرجات Chatterbox تتضمن علامة مائية غير مسموعة (PerTh) يمكن كشفها.

## البنية

```
├── app/        ← تطبيق أندرويد (Kotlin, Compose, Material 3) — com.mahdi.copesaund
├── server/     ← خادم استنساخ FastAPI (Chatterbox MIT / SoproTTS Apache-2.0)
├── models/     ← سكربت تنزيل الأوزان (لا تُرفع الأوزان للمستودع)
├── scripts/    ← أدوات مساعدة
├── docs/       ← بحث مقارنة نماذج الاستنساخ
├── signing/    ← مفتاح توقيع التطبيق (كلمة السر في GitHub Secrets فقط)
└── whisper-main/ ← نسخة OpenAI Whisper (MIT) مرفوعة مسبقاً — للتحويل كلام→نص مستقبلاً
```

## كيف يعمل الاستنساخ؟

نماذج الاستنساخ الصفري (zero-shot) الحالية (Chatterbox ~2GB) لا تعمل عملياً داخل هواتف أندرويد، لذلك يعتمد التطبيق بنية هجينة:

1. **على الجهاز (Offline)**: محرك النص-إلى-كلام المدمج في أندرويد — يعمل بلا إنترنت، بتحكم في السرعة والطبقة، لكنه لا يستنسخ صوتاً من عيّنة.
2. **خادم الاستنساخ (الحقيقي)**: شغّل `server/` على حاسوبك أو أي خادم (Docker بأمر واحد)، ثم أدخل عنوانه في إعدادات التطبيق ← استنساخ حقيقي من عيّنة 3–30 ثانية بدعم 15+ لغة.

```bash
cd server && docker build -t cope-saund-server . && docker run -p 8000:8000 cope-saund-server
# ثم في التطبيق: الإعدادات ← الخادم ← http://192.168.1.10:8000 ← اختبار
```

## ميزات التطبيق

- 🎙 تسجيل عيّنة (3–30 ثانية مع تموّج حي) أو اختيار ملف صوتي

- 🌊 مشغل مع موجة صوتية وشريط تقدم
- 💾 حفظ النتيجة إلى الموسيقى أو مشاركتها
- 🗂 سجل العمليات مع إعادة التشغيل والحذف
- 🌓 مظهر داكن/فاتح تلقائي أو يدوي + ألوان ديناميكية (Material You)

## البناء والتوقيع عبر GitHub Actions

1. افتح **Actions ← Android Build & Sign ← Run workflow**
2. اختر الفرع، وفعّل «Create Release» إن أردت نشر APK، ثم شغّل
3. الناتج: `cope-saund-mahdi.apk` موقّع كـ Artifact، وعند طلب Release يُرفع إلى صفحة [Releases](../../releases)

التوقيع يقرأ من GitHub Secrets إن وُجدت (وإلا يستخدم المفتاح المرفق مع المستودع):

| Secret | الوصف |
|--------|-------|
| `KEYSTORE_BASE64` | محتوى `signing/release.keystore` بترميز Base64 |
| `KEYSTORE_PASSWORD` | كلمة مرور المخزن |
| `KEY_ALIAS` | `cope-saund` |
| `KEY_PASSWORD` | كلمة مرور المفتاح |

> **تنبيه أمني**: نسخة المستودع الحالية تتضمن `signing/keystore.properties` ومفتاح التوقيع داخل المستودع نفسه (مناسب للاستخدام الشخصي فقط). للمشاريع الجادة: أنشئ keystore جديداً على جهازك، احذف ملف `signing/keystore.properties`، وأضف الأسرار الأربعة من إعدادات المستودع ← Secrets ← Actions — سير العمل يُفضّل الأسرار تلقائياً.
