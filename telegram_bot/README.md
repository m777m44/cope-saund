# بوت تليجرام — Cope Saund Mahdi 🎭

بوت تليجرام يربط المستخدمين بخادم استنساخ الأصوات الذاتي الموجود في `../server/`
(Chatterbox Multilingual — ترخيص MIT). لا يعتمد البوت على أي خدمة خارجية تجارية
ولا يقوم بأتمتة تجاوز حدود أي منصة.

## الميزات

- 🎤 استنساخ صوتي من عينة 10–30 ثانية → نص إلى كلام بصوت مُستنسخ
- 🗓 حصة يومية للمستخدمين المجانيين + تهدئة (cooldown) بين العمليات
- 👑 عضوية مدفوعة (بلا حصة) يديرها الأدمن
- 📢 قنوات إجبارية (اشتراك قبل الاستخدام) + زر تحقق
- 🛠 لوحة إدارة: إحصائيات، إذاعة عامة، إيقاف/تشغيل الخدمة، إدارة العضويات والقنوات والحد اليومي
- 🗂 سجل آخر 10 عمليات لكل مستخدم (`/history`) — `/stats` — `/cancel` — `/help`
- 🌍 اختيار لغة النص (العربية، الإنجليزية، الفرنسية، الإسبانية، الألمانية، التركية، الروسية، الهندية)
- 🔒 كل الأسرار عبر متغيرات البيئة فقط — لا توكن في الكود أبدًا

## الإعداد السريع (Docker Compose)

من جذر المستودع:

```bash
cp telegram_bot/.env.example .env
# املأ BOT_TOKEN (من @BotFather) و ADMIN_ID (معرفك الرقمي من @userinfobot)

docker compose up --build -d
```

سيشغّل هذا معًا: الخادم (منفذ 8000) والبوت. للتحقق من جاهزية الخادم افتح
`http://localhost:8000/health` في المتصفح أو استخدم أداة HTTP المفضلة لديك.

## الإعداد اليدوي

```bash
# 1) شغّل خادم الاستنساخ (راجع server/README.md)
cd server && uvicorn server:app --host 0.0.0.0 --port 8000

# 2) شغّل البوت
cd telegram_bot
pip install -r requirements.txt
export BOT_TOKEN="التوكن الجديد من BotFather"
export ADMIN_ID=123456789
export CLONE_SERVER_URL=http://localhost:8000
python bot.py
```

## الأمان — مهم جدًا

- إذا سبق أن وُضع توكن بوت داخل أي ملف أو محادثة: **ألغِه فورًا** عبر
  **@BotFather → /mybots → API Token → Revoke** ثم استخدم التوكن الجديد.
- لا ترفع ملف `.env` أبدًا (موجود في `.gitignore`).
- لا تضع التوكن في كود Python ولا في رسائل الالتزام (commits).

## الواجهة مع الخادم

|---|---|
